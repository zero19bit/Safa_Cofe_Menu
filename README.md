# ☕ کافه صفا — منوی دیجیتال و پنل مدیریت

منوی آنلاین فارسی برای کافه، همراه با پنل مدیریت و API سرور.
مشتری با اسکن QR منو را روی گوشی می‌بیند و مدیر کافه بدون دانش فنی می‌تواند محصولات و قیمت‌ها را به‌صورت زنده تغییر دهد.

> این پروژه در یک کسب‌وکار واقعی در حال استفاده است.

---

## ✨ قابلیت‌ها

### برای مشتری
- منوی واکنش‌گرا (Responsive) با طراحی سبز و کرم و فونت فارسی
- به‌روزرسانی خودکار منو بدون نیاز به رفرش دستی
- دسترسی سریع از طریق کد QR
- بارگذاری سریع روی موبایل

### برای مدیر
- مدیریت محصولات و دسته‌ها با ترتیب دلخواه
- پشتیبانی از انواع قیمت‌گذاری: قیمت عادی، قیمت ویژه، چندقیمتی (مثلاً سایزهای مختلف)، قیمت روز و محصول بدون قیمت
- فعال/غیرفعال‌سازی محصول بدون حذف آن
- آپلود و مدیریت تصویر محصولات
- ویرایش اطلاعات کافه
- نسخه‌ی پشتیبان از منو و تولید QR قابل چاپ

---

## 🛠 تکنولوژی‌ها

| بخش | ابزار |
| --- | --- |
| زمان اجرا | Node.js |
| میزبانی و API | Vercel (Serverless) |
| دیتابیس و ذخیره‌ی فایل | Supabase (PostgreSQL + Storage) |
| احراز هویت | Supabase Auth |
| فرانت‌اند | HTML / CSS / JavaScript، فونت Vazirmatn |
| تست | تست‌های خودکار |

---

## 🧠 اصول طراحی

- **سبک و بدون وابستگی اضافه:** فرانت‌اند ایستا و سرور کوچک
- **امنیت از ابتدا:** احراز هویت سمت سرور، جلوگیری از دسترسی مستقیم به دیتابیس، اعتبارسنجی ورودی‌ها و فایل‌های آپلودی، و عدم ذخیره‌ی داده‌ی حساس در مرورگر
- **تجربه‌ی کاربری ساده برای مدیر:** مدیر کافه بدون کمک برنامه‌نویس بتواند منو را به‌روز کند
- **پایداری داده:** جلوگیری از ناسازگاری و بازنویسی ناخواسته‌ی اطلاعات
